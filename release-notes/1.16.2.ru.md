## Features
- В геомагнитную привязку добавлена встроенная офлайн-карта с обзорными масштабами, координатной сеткой и точкой наблюдения.
- Добавлена возможность принудительного отключения онлайн-карт в INI-файле. По умолчанию онлайн-карты включены.

## Enhancements
- Установщик переведён на x64 с размещением программы в Program Files и поддержкой обновления предыдущей установки.
- При недоступности онлайн-карт автоматически отображается офлайн-карта. Доступна повторная попытка загрузки онлайн-карты.
- Программа обновления поддерживает русскоязычные примечания к выпускам.
- Из установщика исключены устаревшие и неиспользуемые компоненты.

## Bug Fixes
- Исправлен выбор исходных данных для SAG-коррекции при отключении SCC или MSA либо отсутствии результата выбранного метода; устранено возможное аварийное завершение программы.
- В таблице замеров доступны только применимые варианты SCC/MSA и автоматический выбор метода.
- Ручной выбор метода коррекции сохраняется при его временном отключении и повторном открытии проекта.
- Применимость и сохранение результатов SAG определяются по КНБК рейса каждого замера.
- Устранена повторная установка подходящей версии драйвера Sentinel при обновлении программы; исправлены параметры его тихой установки.
